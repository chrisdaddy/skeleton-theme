# Blueprint prompts

Ready-made tasks for the Blueprint AI kit (`mcp/`). Each file is a Markdown prompt with front-matter:

- **In an MCP client** (Claude Desktop, Claude Code, Cursor), they appear as prompts from the `blueprint` server, with their arguments.
- **Elsewhere**, paste the body into any assistant, and fill in the `{{placeholders}}` yourself.

Every prompt follows the kit's rules:
- edits go to a draft theme, as a reviewed diff;
- reviews are quoted word for word;
- prices, savings, stock and ratings come only from the store's own data.
