**Blueprint's rules for honest selling**

The theme is built to show only what's true:
- prices and savings come from your products and subscription plans;
- countdowns end at a fixed time;
- stock, viewer and sales counts appear only when real data exists;
- reviews and ratings come from your review app.

Some features need your data to appear (a review count, a stock level). Until it exists, the feature stays hidden instead of showing a placeholder number.
