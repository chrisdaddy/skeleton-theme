# Getting started

## 1. Install the theme

1. Download the latest `blueprint-<version>.zip` from the [Blueprint Portal](licences.md). Sign in with the email you bought with.
2. In Shopify admin, go to **Online Store → Themes → Add theme → Upload zip file**.
3. The theme is added unpublished. Click **Customize** to set it up before you publish.

Your licence key is in the Portal. You need it for updates (`blueprint update`); the theme itself never checks it.

## 2. Choose a style

Open **Theme settings → Quick style**:

- **Accent color**, used for buttons, selected states and links. Blueprint derives every related colour from it (button text, tinted fills, accessible text versions) and keeps text contrast at 4.5:1 or better.
- **Background**: light or dark.
- **Headings**: sans or serif.
- **Corners**: sharp, soft, round, or custom radii.

Three styles come ready-made: **Clinical** (supplements, wellness), **Editorial** (fragrance, beauty, apparel) and **Bold** (fitness, food, energetic brands). The theme starts on Clinical. Pick another from the theme styles in **Theme settings** (where the theme editor lists them), then adjust the quick style. A style changes colours, type and corners; your pages and content stay as they are.

Finer control (every colour for light and dark mode, fonts, page width, section spacing) is further down **Theme settings**.

## 3. Set up your main product

1. **Product page:** open a product in the editor. The buy box shows the blocks in this order: rating, title, price, benefits, bundle tiers, subscribe & save, add to cart, and trust items.
2. **Bundle tiers:** add a product option called **Pack** with values like "1 pouch", "2 pouches", "3 pouches", and price each variant. The tiers appear automatically. For badges ("Most popular"), gifts and labels, use tier metaobjects (see [Product page](product-page.md)).
3. **Subscribe & save:** install a subscription app (for example Shopify Subscriptions) and create a plan for the product. The toggle shows the plan's real saving.
4. **Reviews:** install a review app that writes Shopify's standard ratings (Judge.me, Okendo, Yotpo, Stamped and Loox do). Stars appear on the product page and product cards.

## 4. Set up the cart

Choose rewards (free shipping, gifts), shipping protection and an upsell in **Theme settings → Cart**. Each reward needs a matching automatic discount; see [Cart](cart-setup.md).

## 5. Add product content (optional)

Benefits, ingredients, clinical results, comparisons, FAQs and the guarantee can live on the product instead of in each section. Fill them in once and they show on the product page, pre-landers and anywhere the product appears.

Create the definitions with the AI kit ("set up Blueprint metafields") or by hand; see [Metafields](metafields.md).

## 6. Pre-landers (optional)

For paid traffic, create a page and choose the **page.advertorial**, **page.listicle** or **page.comparison** template. See [Pre-landers](pre-landers.md).

## 7. Check and publish

- **Preview** on a phone and a desktop.
- **Test a purchase** with your payment provider's test mode. Make sure every reward and gift shows the discount you expect at checkout.
- **Publish** in **Online Store → Themes**.
